# Bakery Website

A simple bakery website created as a personal web development project.

## About the Project

I created this project to practise HTML and CSS while exploring how
a small business could present its products online.

## Features

- Home page
- Product catalogue
- Product presentation
- Payment form interface
- Responsive webpage structure

## Technologies Used

- HTML5
- CSS3

## What I Learned

Through this project, I learned how to structure webpages with HTML,
style interfaces with CSS, organise website files, and design a
simple user experience around a real-world business.

## Future Improvements

- Add JavaScript for interactive features
- Add a backend
- Connect a database
- Implement secure payment processing
- Add an online ordering system
